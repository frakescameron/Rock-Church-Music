🌐 The Rock Church Website

A clean, responsive website built for a local church using HTML, CSS, and JavaScript, focused on clarity, accessibility, and real-world usability.

🚀 Overview

This project is a fully static website designed to serve as the online presence for a local church. It provides essential information, media access, and navigation in a simple, reliable format that works across devices.

Core goals:

Deliver a professional, modern look
Keep the site fast and lightweight
Ensure easy navigation for all age groups
Maintain simple deployment and hosting

🧠 Purpose

This project was built to:

Create a real, usable website for an organization
Strengthen front-end fundamentals (HTML/CSS/JS)
Handle real-world issues like file structure, deployment, and media embedding
Build something that can actually be used and maintained long-term

🛠️ Tech Stack
HTML5 — page structure and content
CSS3 — layout, styling, responsiveness
JavaScript — interactivity and dynamic behavior
GitHub Pages — hosting and deployment


📂 Features
📍 Location & Service Info — clear address and directions
🎧 Music & Media Section — access to worship content
🎥 Past Sermons — embedded media (YouTube / Spotify)
🧭 Navigation System — organized multi-page layout
💡 Custom Styling — tailored design for a clean church-focused aesthetic
💻 Responsive Layout — works across desktop and mobile


🎯 Design Philosophy
Keep it simple and readable
Prioritize real users over flashy design
Ensure fast load times and reliability
Avoid unnecessary complexity


📦 Deployment
The site is hosted using GitHub Pages with a custom domain.
